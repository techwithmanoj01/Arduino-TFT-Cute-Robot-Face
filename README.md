# 🤖 20 Cute Robot Face Animations Using Arduino

A cute animated robot face using Arduino Uno and a 2.4-inch MCUFRIEND TFT LCD display.

Created by Techwithmanoj.

## ✨ Features

- 20 automatic cute face animations
- Blinking and winking eyes
- Happy and sad expressions
- Heart eyes
- Cute blushing expressions
- Crying animations
- Sleeping animations
- Continuous animation loop
- 320 x 240 landscape display
- No SD card or extra sensors required

## 🛠️ Components Required

- Arduino Uno
- 2.4-inch MCUFRIEND TFT LCD Shield
- USB Cable

## 📚 Required Libraries

- MCUFRIEND_kbv
- Adafruit GFX Library

Install both libraries using the Arduino IDE Library Manager.

## 🚀 How to Run

1. Click the green Code button.
2. Select Download ZIP.
3. Extract the ZIP file.
4. Open Cute_Robot_Face.ino in Arduino IDE.
5. Install the required libraries.
6. Connect the TFT shield to Arduino Uno.
7. Select Arduino Uno and the correct COM port.
8. Upload the code and enjoy the animations!
